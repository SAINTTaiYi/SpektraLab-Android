# 02 · 设计系统：暗房（Darkroom）

> 一句话：**把房间关灯，只留一盏安全灯照在相纸上。**
> 照片是界面上唯一亮的东西；其余一切退到 8%–14% 的灰度层次里；琥珀色只做"正在生效的那一个值"。

---

## 1. 五条原则

1. **照片优先**：舞台纯黑，无底色、无描边；所有装饰 ≤ 8% 白。
2. **一屏一主动作**：同屏只有"渲染"是实心/描边按钮，其余是文本。
3. **用间距和字号分层，不用色块分层**：分区靠 24dp 留白 + 1px 细线，不靠填充色。
4. **保留有功能的装饰**：片门参考线、对比分割线、细线保留；大写序号、版本徽标、蓝色块删掉。
5. **可读性下限**：正文 ≥ 12sp，微标 ≥ 10sp，触控 ≥ 44dp，不再出现 6/7/8sp。

---

## 2. 色板（暗色 · 近黑）

| Token | 值 | 用途 | 与 `bg.root` 对比度 |
|---|---|---|---|
| `bg.root` | `#0A0A0B` | 根底、系统栏、顶栏 | — |
| `bg.stage` | `#000000` | 预览舞台（纯黑，照片判读的最中性底） | — |
| `bg.surface` | `#111112` | 参数面板 | — |
| `bg.raised` | `#191A1C` | 底部弹层、下拉、对话框 | — |
| `line.hair` | `#14FFFFFF` (8%) | 分区分割线 | — |
| `line.strong` | `#24FFFFFF` (14%) | 控件描边、ghost 按钮边 | — |
| `line.track` | `#1AFFFFFF` (10%) | 滑杆轨道 | — |
| `text.1` | `#EDECE8` | 主文本（微暖白，接近相纸） | 16.5 : 1 |
| `text.2` | `#A0A099` | 次级文本、说明 | 6.9 : 1 |
| `text.3` | `#82827A` | 微标、未激活、脚注 | 4.8 : 1 |
| `accent` | `#D9A55B` | 安全灯琥珀：当前值、激活下划线、主 CTA 描边、开关 on、词标 | 9.0 : 1 |
| `accent.press` | `#B98A45` | 按压态 | 5.6 : 1 |
| `accent.tint` | `#1FD9A55B` (12%) | 选中行底、极少量高亮 | — |
| `danger` | `#E08A76` | 错误码/失败状态文本 | 7.4 : 1 |
| `on.accent` | `#0A0A0B` | 琥珀填充上的文字/勾 | — |

**为什么是琥珀**：胶片暗房的安全灯就是低饱和琥珀，它不与照片里的任何色相竞争（蓝场会），且 8.4:1 的对比足以承担"当前值"这种信息位。
**若必须保留品牌蓝**：把 `accent` 换成 `#6E7BD8`（去饱和长春花蓝，对 `#0A0A0B` 为 5.2:1），其余 token 不动 —— 这就是换一行的事，也正是 token 化的目的。

**禁止**：任何 `#1C2AA5` / `#3B4BC0` / `#172174` 残留；任何 `< 4.5:1` 的文字；任何整块彩色底（除 `accent` 的 1px 描边与 12% 淡染）。

---

## 3. 字体与字阶

沿用现有两族：`Inter`（拉丁与数字）+ `OPPO Sans`（中文与混排）。

| 角色 | 字号 | 字重 | 字距 | 颜色 | 用在哪 |
|---|---|---|---|---|---|
| `display` | 28sp | Inter Light 300 | 0.02em | text.1 | `NO IMAGE`、`RAW LOADED` |
| `title` | 20sp | Inter Light 300 | 0.00 | text.1 | 词标 `SpektraLab`、弹层标题 |
| `value` | 15sp | Inter Light 300 | 0.01em | text.1 | 下拉当前值、照片尺寸 |
| `accent-value` | 13sp | Inter Light 300 + `tnum` | 0.02em | accent | 滑杆数值（等宽数字，禁止跳动） |
| `body` | 12sp | OPPO Sans | 0.00 | text.2 | 中文标签、说明、按钮 |
| `micro` | 10sp | Inter Regular | 0.10em，全大写仅用于英文 | text.3 | 序号 `(001)`、版本、`135 · 3:2` |

规则：

- **大写 + 字距**只给英文微标；中文一律不加字距、不全大写（当前 `setAllCaps(true)` 打在中文上的地方全部去掉）。
- 数字一律 `setFontFeatureSettings("'tnum' 1")`，滑杆数值列宽固定 48dp。
- 取消负字距（现在的 `-0.065f` / `-0.07f` 是海报手法，小屏上会让 `a/e` 粘连）。仅 `display` 用 `+0.02em` 做拉开。
- 行高：`display` 1.15；`body` 1.5；`micro` 1.3。

---

## 4. 间距、栅格、圆角

- 基准 **4dp**；常用档 `4 / 8 / 12 / 16 / 24 / 32`。
- 页面左右边距 **20dp**；面板内行左右 **20dp**；细线两端与文字对齐（不内缩）。
- 分区之间 **24dp**；行与行之间用 1px `line.hair`，不加额外间距。
- 行高：下拉行 48 / 滑杆行 56 / 开关行 48 / 操作栏 56 / 顶栏 48 / 面板头 44。
- 圆角：**默认 0**（相纸/片基都是直角）；仅 `2dp` 用于 ghost 按钮与开关本体，`14dp` 用于底部弹层的上方两角。**不使用投影**，层级只靠底色与细线。

## 5. 组件规格

### 5.1 顶栏 `TopBar`（48dp）
- 左：`SpektraLab` 20sp Light text.1，字距 0.00；`v1.2.6` 10sp text.3，基线偏移 +3dp，左边距 8dp。
- 右：空。关于/更新从面板脚注进入（长按词标仍保留为快捷方式）。
- 底：无细线（舞台纯黑直接接上，减少一条线）。

### 5.2 舞台 `Stage`
- 底 `bg.stage` 纯黑；照片 `FIT_CENTER`，内边距 12dp。
- 覆盖信息（不在照片上压任何底色，只给文字）：
  - 左上：文件名 12sp text.2，单行，最大 60% 宽，末尾省略；
  - 右上：`135 · 3:2` 10sp text.3（有画幅信息时才出现）；
  - 左下：仅在**首次渲染成功后**出现一行 10sp text.3 手势提示「长按看原片 · 拖动分割」，`SharedPreferences` 记住，第二次渲染起不再出现。
- 空状态（居中，间距 12/16）：
  - `(001)` 10sp text.3 字距 0.10em
  - `NO IMAGE` 28sp Light text.1
  - `选择一张 RAW 或 JPEG 开始` 12sp text.2
  - ghost 按钮 44dp：1px `line.strong`、圆角 2、左右 16dp 内边距、`选择照片` 12sp text.1 + 12dp 手绘箭头（沿用 `ArrowView`，改色）
- RAW 已加载：`RAW LOADED` 28sp + 文件名 12sp text.2 + 一行 10sp text.3「点「渲染」得到胶片图」。
- 渲染中：照片与覆盖层整体 `alpha 0.35`（160ms 淡出）；舞台底部一条 **1dp 琥珀 indeterminate 线**（宽 100%，`accent` 40%）；不出现居中大字 `RENDERING`（那是海报语言，暗色下会刺眼）。
- 参考线 `GuideView`：仅在空状态显示；线宽 1px，颜色 6% 白，角标 24% 白、长 11dp。

### 5.3 操作栏（v1 常驻版；极简版按 05 的「底部两文字动作 + 一个主按钮」执行）
```
│ 导入                                      导出 │  ┌──────────┐
│                                               │  │   渲染   │
└───────────────────────────────────────────────┴──┴──────────┘
```
- 左：`导入` 12sp text.2（44dp 命中，含 8dp 内边距）；**长按 = 三入口菜单**（相册 / 文件 / 原生尺寸），与现状一致。
- 右组：`导出` 12sp text.2（长按 = 全尺寸导出）＋ 1×16dp 竖细分隔 + 主 CTA。
- 主 CTA `渲染`：高 44dp，1px `accent` 描边、圆角 2、左右 20dp，文字 12sp `accent`；无照片时降为 `line.strong` 描边 + text.3 文字（禁用态，不隐藏，保持位置稳定）。
- 顶边 1px `line.hair`。

### 5.4 参数面板 `LookPanel`（可收起）

**收起态 44dp**（默认）
```
│ Portra 400 · Endura · 135                                   ⌄ │
```
- 左：当前配方单行 12sp text.1，超长中段省略；右：12dp chevron（手绘 1px 两笔），text.3，随展开旋转 180°。
- 整行 44dp 可点；左右 20dp。
- 展开/收起动画：180ms，`DecelerateInterpolator`，舞台高度随之变化（不是覆盖在照片上）。

**展开态 = 头部 44 + 分段 40 + 细分线 1 + 内容 184 ≈ 268dp（最大 300dp，内容可滚）**
- 头右：`重置` 10sp text.3（44dp 命中）。
- 分段控件 `SegmentedTabs`（40dp）：`胶片 / 光学 / 画幅 / 边角`，12sp；激活 text.1 + 底部 2dp `accent` 下划线（宽 24dp，居中于文字）；未激活 text.3；**去掉 `01/02/03` 序号**。点击命中区 = 每段等分的 40×≥88dp。
- 内容区行规格：
  - `FieldRow` 48dp：左标签 12sp text.2；右值 15sp text.1（单行省略）；chevron 12dp text.3；行间 1px `line.hair`。点击 → 底部弹层选值。
  - `SliderRow` 56dp：上行 20dp（标签 12sp text.2 / 值 13sp `accent` 等宽右对齐 min 48dp）；下行 36dp 触控区：轨 2dp `line.track`、已选段 2dp `accent`、拇指 12dp 圆 `#EDECE8` + 1px `accent` 环。**松手才提交**（沿用现有 `onStopTrackingTouch` 里 `applyParams()+renderImage()` 的语义）。
  - `ToggleRow` 48dp：标签 12sp text.2；右 18×18dp 方形（圆角 2、1px `line.strong`；on = `accent` 填充 + `on.accent` 勾）。
  - `NoteRow`：10sp text.3，行高 1.5，如「颗粒与光晕按 135 全画幅 36mm 计算」。
  - `FooterRow` 40dp：左 `SpektraLab v1.2.6` 10sp text.3；右 `关于` 10sp text.3（44dp 命中）→ 关于弹层。

### 5.5 底部弹层 `Sheet`（替换全部 `AlertDialog` 与 `Spinner` 下拉）

- 底 `bg.raised`，上两角 14dp，顶部 40×2dp 手柄 `#33FFFFFF`，遮罩 `#000000` 60%。
- 标题 20sp Light text.1，左 20dp / 上 20dp / 下 8dp。
- 列表行 56dp：15sp 文字 text.1；选中行 = `accent` 文字 + 右侧 12dp 勾；行间 1px `line.hair`。
- 说明段落（如原生导入的设备上限警告）12sp text.2、行高 1.5，段间 12dp。
- 底部按钮区 56dp：ghost `取消`（text.2）+ 主 `继续`（`accent` 文字）。底内边距并入导航栏 inset。
- 出现动效：从下 24dp 处 220ms 滑入 + 遮罩 160ms 淡入；返回键与遮罩点击关闭。

### 5.6 反馈

- **不用 Toast 承载错误**：失败 → 状态行变 `danger`，同行右侧「详情」→ 弹层（错误码 E-xxxx + 原文）。成功 → 状态行 text.2 保留 4 秒。
- 状态行位置：面板收起时贴在操作栏上方（44dp 行内右对齐），收起时也始终可见，**字号 10sp，最长一行中段省略**。

## 6. 状态模型（把 63 处零散 setText 收敛成 7 个状态）

| 状态 | 触发 | 舞台 | 主 CTA | 状态行 |
|---|---|---|---|---|
| `EMPTY` | 启动 / 清空 | 空状态 | 禁用 | 空 |
| `RAW_READY` | RAW 元数据就绪 | RAW LOADED + 文件名 | 可用 | `RAW 已载入` |
| `SOURCE_READY` | 图片导入完成（未渲染） | 照片 + 文件名 | 可用（动词=渲染） | `本地预览` |
| `RENDERING` | 渲染中 | 照片 alpha .35 + 琥珀线 | 禁用 | `渲染中` |
| `RENDERED` | 渲染成功 | 照片 + 对比层 | 可用（动词=重新渲染） | `预览就绪 2048×1365` |
| `EXPORTING` | 导出中 | 不变，线在 | 禁用 | `导出中 · 68%`（按阶段文案） |
| `ERROR` | 任意失败 | 保留上一帧 | 按可用性 | `danger` + `[E-xxxx]` + 详情 |

`setStage(0/1/2)` 保留，新增 `setUiState(UiState)` 统一驱动上述可见性；旧文案表映射到新文案（中文化、去掉 `…` 与全大写混排）。

## 7. 动效

| 场景 | 时长 | 曲线 |
|---|---|---|
| 面板展开/收起 | 180ms | Decelerate |
| 弹层进出 | 220 / 180ms | Decelerate |
| 渲染开始（照片变暗） | 160ms | Linear |
| chevron 旋转 / 开关填充 | 120ms | Decelerate |

原则：只动"位置与透明度"，不做缩放弹跳；渲染中不放循环动画（除了那条 1dp 线）。

---

## 8. 无障碍

- 所有可点元素 `contentDescription`：`导入` →「导入照片，长按打开更多导入方式」；分段项 →「胶片参数，第 1 项，共 4 项」+ `setSelected`。
- 触控 ≥ 44dp（`View.setMinimumHeight` + `TouchDelegate` 兜住描边小控件）。
- 对比度：text.1 16.5:1、text.2 6.9:1、text.3 4.8:1（仅用于非关键微标，且 ≥10sp）、accent 8.4:1。
- 支持 `fontScale` 放大：所有行高用 `wrap_content` + `minHeight`，不用固定高度截断文字；`display` 类字号用 `sp` 且 200% 时不换行溢出（允许两行）。
- 关闭系统强制深色：`android:forceDarkAllowed=false`（我们自己是深色，不允许系统二次反色）。
