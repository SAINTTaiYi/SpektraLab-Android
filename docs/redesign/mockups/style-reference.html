Inter 300 负责数字与大字；Inter 400 负责英文微标（仅英文才加字距/大写）；OPPO Sans 负责中文。数字一律 tnum 等宽，滑杆值不抖动。
下限 正文 12sp、微标 10sp，工程内不得出现 6/7/8/9sp。
字距 取消负字距（旧版 −0.065em 会让小字粘连）；仅 display 用 +0.02em。
中文 不全大写、不加字距。
层级 只靠字号 + 颜色两档（16.5:1 / 6.9:1），不用加粗堆叠。
