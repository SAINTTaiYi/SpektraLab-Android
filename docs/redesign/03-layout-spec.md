# 03 · 布局规格（Layout Spec）

> 参考视口 **390 × 844 dp**（`mdpi` 下 1dp = 1px，本文档所有数字均为 dp）。
> 坐标系：从状态栏 inset 之下开始；所有高度不含系统栏。

---

## 1. 骨架（重构后）

```
┌────────────────────────────────────────────────┐
│ TopBar                                    48dp │  SpektraLab 20sp + v1.2.6 10sp
├────────────────────────────────────────────────┤
│                                                │
│                                                │
│                    STAGE                       │  纯黑舞台（flex）
│              （照片 FIT_CENTER）                │  最小 52% 可用高
│                                                │
│  [文件名 12sp]                    [135·3:2 10sp]│  覆盖信息，无底色
├────────────────────────────────────────────────┤
│                             预览就绪 2048×1365 │  状态行 20dp（贴舞台下沿）
├────────────────────────────────────────────────┤
│ Portra 400 · Endura · 135                   ⌄  │  LookPanel 收起 44dp
├────────────────────────────────────────────────┤
│ 导入                          导出 │ [ 渲染 ]  │  ActionBar 56dp
├────────────────────────────────────────────────┤
│                   （导航栏 inset）              │
└────────────────────────────────────────────────┘
```

高度预算（390×844，状态栏 24 / 手势导航 inset 24 → 可用高 796）：

| 区块 | 收起态 | 展开态 |
|---|---|---|
| TopBar | 48 | 48 |
| Stage | 796 − 48 − 20 − 44 − 56 = **628** | 796 − 48 − 20 − 268 − 56 = **404** |
| 状态行 | 20 | 20 |
| LookPanel | 44 | 268 |
| ActionBar | 56 | 56 |
| 舞台占比 | **78.9%**（占可用高） | **50.8%** |

→ 收起态照片占近 8 成高度，符合"照片优先"；展开态仍有 404dp 可判读（约 300dp 宽照片区）。面板内容滚动，不再写死 178dp。

### 3.4 对比中
- 长按：全屏显示原片（无任何覆盖层，立即切换）。
- 拖动：分割线 1px `line.hair` 加强到 `#B3FFFFFF`？——**改为 `accent` 40% 1px + 12dp 圆环手柄**（`accent` 环、`bg.stage` 填充），比现在的纸白块更克制也更清楚。
- 点击：回到整幅；无模式残留。

### 3.5 渲染中
- 照片 alpha 0.35（160ms），顶部覆盖信息一并变暗；
- 舞台底部 1dp 琥珀 indeterminate 线；
- 主 CTA 禁用；状态行 `渲染中`。

### 3.6 导出中
- 状态行显示阶段：`导出中 · 渲染中 3 秒` → `导出中 · 写入相册 4096×2731`；
- 同一条 1dp 线复用（在舞台底部，不新增第二个进度条）；
- 完成：状态行 `已导出 4096×2731 · 4.2 MB`（保留 6 秒，text.2）。

### 3.7 错误
- 状态行 `danger`：`渲染失败 [E-1201]` + 右侧 `详情`；
- 详情弹层：标题 `渲染失败`，正文含错误码全文与建议（沿用 `SpkError.format`），主按钮 `知道了`；
- 不改变舞台内容（保留上一帧照片），不清空参数。

### 3.8 弹层（三种）
| 弹层 | 触发 | 内容 |
|---|---|---|
| 导入方式 | 长按`导入` | 三行：从相册选择 / 从文件选择（RAW·HEIC）/ 按原始尺寸导入 |
| 导出档位 | 点`导出` | 三行：长边 2048（最快）/ 长边 3400 / 全尺寸（附设备上限说明）；副标题 = `probe.describe()` |
| 关于 | 面板脚注`关于` | 设备能力、引擎与许可、`检查更新` / `打开 GitHub` 两行 |
| 原生尺寸确认 | 选第三入口 | 说明段 + `取消` / `继续` |
| 值选择器 | 点 `FieldRow` | 该字段的候选列表（胶片 25 / 相纸 9 / 画幅 9 / 片门 ≤10），选中态琥珀 + 勾 |

## 5. 决策点（需要你拍板的 3 件事）

**决策 A · 状态行位置**
- A1（推荐）：状态行做成舞台下沿的一条 20dp 细行（面板之上），收起/展开都常驻 → 稳定、无跳动、可读；代价是多 20dp。
- A2：状态行放在面板头左端、替换配方摘要 2 秒后回落 → 省空间，但会把关键信息挤掉。

**决策 B · 面板默认态**
- B1（推荐）：默认收起（照片优先，首次进入直接看到大图）。
- B2：默认展开（老用户调参路径最短，但首屏照片只有 39%）。

**决策 C · 主 CTA 文案随状态变化**
- C1（推荐）：`渲染` → `重新渲染`（成功后）→ `渲染中…`（禁用）。
- C2：恒定 `渲染`，只改禁用态 → 更静，但状态少一层反馈。

## 6. 适配规则

| 场景 | 规则 |
|---|---|
| 360dp 宽（小屏） | 左右边距 16dp；`display` 26sp；滑杆值列 44dp；动作栏主 CTA 左右 16dp |
| 390–430dp | 基准规格 |
| ≥ 600dp（平板/折叠展开） | 舞台与面板改左右分栏：舞台 62% 宽，面板 38% 宽、常驻展开；动作栏竖排在最右 |
| 横屏 | 舞台左 58% / 面板右 42%，动作栏并入面板底部 |
| 字体放大 200% | 行高 `wrap_content` + `minHeight`；面板内容滚动；`display` 允许两行 |
| 手势导航 / 三键 | 底内边距 = 导航栏 inset + 8dp（用 `getInsets(Type.navigationBars())` 已有代码路径扩展） |
| 旋转 | 现在 `configChanges` 保留 Activity 但不重算字号 → 新增 `onConfigurationChanged` 重算 `wordmarkSp/fontScale` 并重建尺寸（见 04 文档 P3） |
